# Student Information System

A simple Python-based Student Information System

## Features

- Add Student
- View Students
- View Student by ID
- Update Student
- Delete Student
- Save data using JSON
- Logging
- Unit Testing

## How to Run

Open the terminal in the project folder and type

python -m src.main

## How to Test

Type

python -m unittest discover -s tests -v
